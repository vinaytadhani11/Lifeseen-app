Backend for this Flutter app is Firebase Realtime Database
(whatsapp-mode-default-rtdb), under screenTime/. The Android source used
Firestore arrays. The same fields are stored here as maps so add/remove
stays atomic.

Logout and delete clear the friends session and onboarding only.
WhatsApp keys stay, so page_log = 1 is not wiped.

On phones that are not Android, Usage Access cannot be granted.
The permission screen is skipped there so the rest of the flow can open.
Android uses the usage-stats channel in UsageStatsBridge.kt.
